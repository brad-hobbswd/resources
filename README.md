# 📚 Bradley Hobbs Resource Library

## Faith. Learning. Creativity. Transformation.

Welcome to the **Bradley Hobbs Resource Library**, a collection that brings together years of teaching resources, written works, devotional collections, books, memoirs, stories, creative projects, and professional web development.

This library represents different areas of work created by **Bradley Hobbs**, including education, faith based writings, books, memoirs, personal stories, literary works, photography, and client website projects.

---

# 🌟 About This Project

The Resource Library serves as a central location to explore and discover:

- Educational resources for teachers and classrooms
- Books, memoirs, and long form writing
- Faith writings and devotional collections
- Stories, novels, and literary works
- Personal testimonies and life experiences written into words
- Creative projects and photography
- Professional website development projects

Not every written work is a devotional. Some works are memoirs. Some are stories. Some are novels or literary parables. Some are faith studies or devotional reflections. Others take real life experiences and turn them into words so that readers can explore healing, truth, struggle, identity, faith, courage, relationships, and transformation.
